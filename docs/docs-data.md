# Структуры данных

## Динамический массив (dyn_arr.h)
* `dyn_arr_init(capacity)` — создает новый массив с начальным размером в куче.
* `dyn_arr_push(da, val)` — добавляет элемент в конец (выделяет память, если нет места).
* `dyn_arr_get(da, index)` — возвращает элемент по индексу с проверкой на выход за границы.
* `dyn_arr_free(da)` — полностью очищает массив и освобождает память в куче.
