# Алгоритмы

## Сортировка (sort.h)
* `bubble_sort(arr, size)` — сортирует массив целых чисел пузырьком (медленно, O(n²)).
* `quick_sort(arr, size)` — быстрая сортировка массива методом Хоара (быстро, O(n log n)).

## Поиск (search.h)
* `linear_search(arr, size, key)` — ищет элемент перебором, возвращает индекс или -1.
* `binary_search(arr, size, key)` — быстрый поиск в отсортированном массиве за O(log n).
